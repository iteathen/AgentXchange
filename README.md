# AgentXchange

**Agent X-Change** is an ISOgraph-defined formal language for structured communication of knowledge between agents.

The project is currently in early specification research. Its working architectural hypothesis is that Agent X-Change is constructed inside a constrained subset of ISOgraph Knowledge rather than introducing an independent semantic substrate.

Current candidate specification:

- [Agent X-Change Specification — Draft 0.1 Candidate](AGENT_X_CHANGE_SPEC_DRAFT_0_1_CANDIDATE.md)

The first draft is intentionally architectural. Surface syntax, wire encoding, transport, runtime algorithms, cryptography, scheduling, storage, and optional deeper ISOgraph analysis remain unfrozen.
